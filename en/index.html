What is Termux ZIM Maker?

Termux ZIM Maker is a lightweight C++ command-line tool that packages local HTML folders into .zim files for offline reading with Kiwix. It runs natively on Termux (Android), Alpine Linux, Debian, and Ubuntu — without proot, glibc, Python, or Node.js.

Key Features

  • Recursively scans a directory and packs all files into a ZIM archive
  • Auto-detects MIME types for common file extensions
  • Sets index.html (or the first HTML file) as the welcome page
  • Generates a full-text search index powered by Xapian
  • Writes metadata: title, description, language
  • Outputs ZIM6 format (lzma2 / zstd), compatible with Kiwix 3.0+

Quick Start

pkg install libzim kiwix-tools
chmod +x make_zim
./make_zim --dir ~/myhtml --out demo.zim --title "Demo" --lang zh
