Synopsis

make_zim --dir <html_dir> --out <output.zim>
         --title <title> [--desc <desc>] [--lang <lang>]

Options

OptionRequiredDescriptionDefault
--dirYesPath to the local HTML folder (recursively scanned)—
--outYesOutput ZIM filename—
--titleYesTitle written into ZIM metadata—
--descNoDescription written into ZIM metadataCreated on Termux
--langNoISO 639 language code (e.g. eng, zh, zhp)eng
--helpNoShow help message and exit—
--versionNoPrint version and exit—

Exit Codes

CodeMeaning
0Success
1General error (invalid arguments, I/O failure)
2ZIM creation failed (libzim error)
