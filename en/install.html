Termux (Android)

pkg update
pkg install -y clang libc++ libzim pkg-config kiwix-tools

libzim is provided as a native aarch64 bionic build at /data/data/com.termux/files/usr/lib/libzim.so. No proot or glibc needed.

Alpine Linux

apk add clang libc++-dev pkgconf libzim-dev zlib-dev icu-dev xz-dev zstd-dev xapian-core-dev

Debian / Ubuntu

apt update
apt install -y clang libc++-dev pkg-config libzim-dev kiwix-tools

Build from Source

git clone https://github.com/zimmaker/termux-zim-maker.git
cd termux-zim-maker
./build.sh

Or manually:

clang++ make_zim.cpp -o make_zim -Ivendor $(pkg-config --cflags --libs libzim) -std=c++17

Verify Installation

./make_zim --help

You should see the usage banner printed.
