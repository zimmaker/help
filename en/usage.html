Example 1: Minimal Pack

Create a simple HTML folder and package it:

mkdir -p ~/myhtml/sub
echo '<html><body><h1>Home</h1><a href="sub/page.html">Sub</a></body></html>' > ~/myhtml/index.html
echo '<html><body><h1>Sub Page</h1><p>Hello ZIM</p></body></html>' > ~/myhtml/sub/page.html
./make_zim --dir ~/myhtml --out demo.zim --title "Demo Site" --lang zh

Example 2: With Description

./make_zim --dir ~/wiki --out wiki.zim --title "My Wiki" --desc "Offline wiki snapshot" --lang eng

Example 3: Verify with kiwix-tools

kiwix-manage demo.zim --show
kiwix-serve --port=8080 demo.zim
kiwix-search demo.zim "Hello"
  • kiwix-manage --show: lists metadata and articles inside the ZIM
  • kiwix-serve: serves the ZIM over HTTP for browser access
  • kiwix-search: performs a full-text search (requires Xapian index)

Example 4: Package a Static Blog

./make_zim --dir ~/blog/public --out blog.zim --title "My Blog" --desc "Offline blog archive" --lang zhp

Point your static site generator (Hugo, Jekyll, Hexo) output to --dir and you get an offline-readable ZIM.

Example 5: Batch Processing

for dir in ~/sites/*/; do
  name=$(basename "$dir")
  ./make_zim --dir "$dir" --out "${name}.zim" --title "$name" --lang zh
done
