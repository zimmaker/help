Q: Kiwix opens my ZIM but shows a blank page. Why?

A: Make sure your folder contains an index.html at the root. Termux ZIM Maker sets the first HTML file as the welcome page, but if your entry point is named differently (e.g. main.html), rename it to index.html.

Q: pkg-config --libs libzim returns nothing. How do I fix it?

A: Install pkg-config first: pkg install pkg-config. Then verify libzim.pc exists in /data/data/com.termux/files/usr/lib/pkgconfig/.

Q: Can I run this on a PC (not Termux)?

A: Yes. It works on Alpine, Debian, Ubuntu, and any Linux with libzim 9.x. The binary is a standard ELF executable.

Q: Does it support images, CSS, and JavaScript inside the ZIM?

A: Yes. Any file type is packaged. MIME types are auto-detected for common extensions. Unknown extensions default to application/octet-stream.

Q: How large can the input folder be?

A: All files are read into memory at once. For directories under ~500MB this is fine. For GB-scale input, ensure at least 4GB RAM or use libzim's streaming API directly.

Q: Is the output ZIM6 or ZIM5?

A: ZIM6 (lzma2 / zstd compression), compatible with Kiwix 3.0 and later.

Q: Why not use zimwriterfs?

A: zimwriterfs is a great tool but depends on glibc and FUSE, which are not available in bare Termux. Termux ZIM Maker is a single static-friendly binary with no FUSE dependency.

Q: Search doesn't return results. What's wrong?

A: Full-text search requires the Xapian index. Make sure libzim was built with Xapian support (default in Termux apt). Use kiwix-search output.zim "keyword" to test.
