什么是 Termux ZIM Maker？

Termux ZIM Maker 是一款轻量 C++ 命令行工具，能将本地 HTML 文件夹打包成 .zim 文件，供 Kiwix 离线阅读。它原生运行于 Termux（Android）、Alpine Linux、Debian 和 Ubuntu —— 无需 proot、glibc、Python 或 Node.js。

核心功能

  • 递归扫描目录，将所有文件打包进 ZIM 档案
  • 自动识别常见文件扩展名的 MIME 类型
  • 将 index.html（或第一个 HTML 文件）设为欢迎页
  • 基于 Xapian 生成全文搜索索引
  • 写入元数据：标题、描述、语言
  • 输出 ZIM6 格式（lzma2 / zstd），兼容 Kiwix 3.0+

快速开始

pkg install libzim kiwix-tools
chmod +x make_zim
./make_zim --dir ~/myhtml --out demo.zim --title "Demo" --lang zh

详细步骤见 安装指南 和 使用示例。
