Q：Kiwix 打开 ZIM 后显示空白页，怎么办？

A：确认目录根目录下有 index.html。Termux ZIM Maker 会将第一个 HTML 文件设为欢迎页，但如果入口文件命名不同（如 main.html），请重命名为 index.html。

Q：pkg-config --libs libzim 没有输出，怎么解决？

A：先安装 pkg-config：pkg install pkg-config。然后确认 /data/data/com.termux/files/usr/lib/pkgconfig/ 目录下存在 libzim.pc 文件。

Q：能在电脑上运行吗（非 Termux 环境）？

A：可以。支持 Alpine、Debian、Ubuntu 等任意安装了 libzim 9.x 的 Linux 系统。二进制是标准 ELF 可执行文件。

Q：ZIM 内支持图片、CSS 和 JavaScript 吗？

A：支持。所有文件类型都会被打包。常见扩展名会自动识别 MIME 类型，未知类型默认设为 application/octet-stream。

Q：输入文件夹最大支持多大？

A：当前实现将所有文件一次性读入内存。500MB 以内的目录没有问题。GB 级输入建议至少 4GB 内存，或直接使用 libzim 的流式写入接口。

Q：输出的是 ZIM6 还是 ZIM5？

A：ZIM6（lzma2 / zstd 压缩），兼容 Kiwix 3.0 及以上版本。

Q：为什么不用 zimwriterfs？

A：zimwriterfs 依赖 glibc 和 FUSE，在裸 Termux 环境中不可用。Termux ZIM Maker 是单一静态友好二进制，无 FUSE 依赖。

Q：搜索没有返回结果，怎么回事？

A：全文搜索需要 Xapian 索引。确认 libzim 编译时启用了 Xapian 支持（Termux apt 默认已启用）。使用 kiwix-search output.zim "关键词" 测试。
